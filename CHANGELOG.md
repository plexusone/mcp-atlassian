## [v0.3.0] - 2026-07-25

### Highlights

- Jira skill with 18 MCP tools for issues, agile boards, sprints, and reports
- Dual-skill MCP server combining Confluence and Jira under shared Atlassian auth
- Module renamed from mcp-confluence to mcp-atlassian

### Breaking

- Module path changed from `github.com/plexusone/mcp-confluence` to `github.com/plexusone/mcp-atlassian` ([`ba614cd`](https://github.com/plexusone/mcp-atlassian/commit/ba614cd))
- Removed `confluence/`, `storage/`, `mcpserver/`, and `cmd/mcp-confluence/` packages (migrated to `github.com/grokify/go-atlassian`) ([`ba614cd`](https://github.com/plexusone/mcp-atlassian/commit/ba614cd))

### Upgrade Guide

- Update import paths from `mcp-confluence` to `mcp-atlassian`
- Update `go install` path to `github.com/plexusone/mcp-atlassian/cmd/mcp-atlassian@latest`
- Update env var `CONFLUENCE_BASE_URL` to `ATLASSIAN_URL` (no `/wiki` suffix)
- Update Claude Desktop server key from `confluence` to `atlassian`

### Added

- Jira omniskill with 18 tools: search, create, update, clone, bulk-update, transitions, boards, sprints, velocity, burndown, worklog, and cycle-time reports ([`502cc47`](https://github.com/plexusone/mcp-atlassian/commit/502cc47))
- Dual-skill `cmd/mcp-atlassian` server with shared Atlassian auth, stdio and HTTP modes, OAuth 2.1/PKCE, and optional ngrok tunneling ([`502cc47`](https://github.com/plexusone/mcp-atlassian/commit/502cc47))

### Changed

- Module renamed from `mcp-confluence` to `mcp-atlassian` ([`ba614cd`](https://github.com/plexusone/mcp-atlassian/commit/ba614cd))
- Env var `CONFLUENCE_BASE_URL` replaced by `ATLASSIAN_URL` (no `/wiki` suffix) ([`ec335e5`](https://github.com/plexusone/mcp-atlassian/commit/ec335e5))

### Dependencies

- Upgrade `github.com/grokify/go-atlassian` to v0.32.0 ([`fc3ec27`](https://github.com/plexusone/mcp-atlassian/commit/fc3ec27))
- Upgrade `github.com/plexusone/omniskill` from v0.8.0 to v0.9.0 ([`659f17c`](https://github.com/plexusone/mcp-atlassian/commit/659f17c))
- Update all transitive dependencies ([`b26aa09`](https://github.com/plexusone/mcp-atlassian/commit/b26aa09))

### Documentation

- Rename all docs from mcp-confluence to mcp-atlassian, add Jira tools ([`ec335e5`](https://github.com/plexusone/mcp-atlassian/commit/ec335e5))
- Update credential names from confluence to atlassian ([`f931c7c`](https://github.com/plexusone/mcp-atlassian/commit/f931c7c))

## [v0.2.0] - 2026-05-24

### Highlights

- Composable omniskill architecture for modular, reusable MCP skills
- Vault-backed credentials via omnitoken (1Password, Bitwarden, file, env)
- Cobra CLI with subcommands and direct tool invocation

### Breaking

- Module path changed from `github.com/agentplexus/mcp-confluence` to `github.com/plexusone/mcp-confluence` ([`0a3b89f`](https://github.com/plexusone/mcp-atlassian/commit/0a3b89f))
- CLI now uses cobra with `--flag` style instead of `-flag` ([`978eb21`](https://github.com/plexusone/mcp-atlassian/commit/978eb21))

### Upgrade Guide

- Update import paths from `agentplexus` to `plexusone`
- Update CLI flag syntax from `-flag` to `--flag`
- Update `go install` path to `github.com/plexusone/mcp-confluence/cmd/mcp-confluence@latest`

## [v0.1.0] - 2025-12-29

### Highlights

- Initial release with MCP tools for safe Confluence page editing
- Structured content blocks for creating and reading pages
- Lossless XHTML round-trip editing for complex pages

### Added

- `confluence_read_page` tool for reading pages as structured content blocks ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
- `confluence_read_page_xhtml` tool for reading pages as raw Storage Format XHTML ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
- `confluence_update_page` tool for updating pages with structured content blocks ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
- `confluence_update_page_xhtml` tool for updating pages with raw XHTML ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
- `confluence_create_page` tool for creating new pages with structured blocks ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
- `confluence_create_table` tool for creating table blocks from structured data ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
- `confluence_delete_page` tool for deleting pages by ID ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))

- Confluence REST API client with basic authentication ([`df233c7`](https://github.com/plexusone/mcp-atlassian/commit/df233c7))
